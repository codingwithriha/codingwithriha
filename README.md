## About

I'm a Frontend Developer with a focus on React and TypeScript, building scalable web applications that are fast, accessible, and a pleasure to use. My work sits at the intersection of engineering discipline and design sensibility — I care deeply about both the code quality behind the scenes and the experience people have in front of it.

Most of my recent work has been in SaaS products and data-rich dashboards, where performance, component architecture, and UI polish all have to pull in the same direction.

I also run **[Coding with Riha](https://youtube.com/@codingwithriha)** — a YouTube channel where I share frontend development insights, walkthroughs, and modern web dev techniques.
